# Submission checklist, checked against the official Rules page (rules sections in brackets)
Official rules: https://paypalaihackathon.devpost.com/rules  (rules can be amended; recheck before submitting)

## Deadlines [1]
- Submission closes Thu Nov 12, 2026, 12:00 pm Pacific (= 1:30 AM IST Nov 13). No edits after that [5]. Target Nov 11.
- Project must stay free and unrestricted for judges until the Judging Period ends: Tue Dec 15, 2026, 8:00 am Pacific [4 Testing]
- Winners announced around Dec 21, 2026

## Eligibility [3]
- [ ] Every member is at least the age of majority where they live
- [ ] Not a resident of Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea or any OFAC-sanctioned place
- [ ] No tie to PayPal, Devpost, a judge, or their employers/affiliates (or immediate family/household of them)
- [ ] One authorized Representative on Devpost if a team
- [ ] Project not built with funding, contract or commercial license from PayPal or Devpost [4]

## Project [4]
- [ ] PayPal developer platform in the free SANDBOX is central (Orders, webhooks, Agent Toolkit are in the starter)
- [ ] An AI tool/model/platform is built in meaningfully
- [ ] Installs and runs consistently and works as shown in video and description
- [ ] New, or existing but significantly updated after Oct 1, 2026 (explain the updates)
- [ ] Authorized to use every third-party SDK/API/data (OpenAI, Channel3, etc.) under their terms
- [ ] Original, solely owned work; open-source parts used within their licenses

## Required submission items [4]
- [ ] Text description of features and functionality
- [ ] Functional demo access: either complete setup/run instructions in the repo OR a hosted URL (public hosting is NOT required). Mockups/static prototypes do not count
- [ ] Public repo on GitHub, Bitbucket or GitLab with all source, assets and instructions
- [ ] Open-source LICENSE file, visible in the repo's About section (replace the name placeholder)
- [ ] Demo video: under 3 minutes, shows the project working on its device, public on YouTube, link on the form
- [ ] Video has no third-party trademarks or copyrighted music/material without permission
- [ ] Overview page also asks you to name the AI tools/models used and how (README has this section)
- [ ] All materials in English

## Testing access [4]
- [ ] Setup/run instructions plus any test account or sandbox login details needed, in README or project description
- [ ] If anything is private, login credentials included in the testing instructions
- [ ] Use throwaway sandbox-only accounts/keys; never commit real secrets; rotate any key you share after Dec 15

## Prizes you can target [8]
- A project can win one Grand Prize + one Sponsor Prize, OR one Honorable Mention + one Sponsor Prize
- Sponsor prizes require using that sponsor's tools (Channel3, Render, AG Grid, APIMatic, Bryntum). Read each sponsor's page on Devpost for extra guidance
- Winners must return forms within 10 business days; non-US winners may need a W-8BEN; taxes and bank fees are yours

## Final
- [ ] Ambiguous rule? Send a written clarification request BEFORE the deadline [11]
- [ ] After submitting, confirm Devpost shows the submission (proof of sending is not proof of receipt) [9]
